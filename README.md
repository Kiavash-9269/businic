# Businic

وب‌سایت معرفی Businic — React + Vite + Tailwind CSS v4 + NestJS Contact API

## شروع سریع

راهنمای کامل راه‌اندازی: **[GETTING_STARTED.md](GETTING_STARTED.md)**

```powershell
npm install
cd server; npm install; cd ..
Copy-Item server\.env.example server\.env
npm run dev:server   # ترمینال ۱
npm run dev          # ترمینال ۲
```

## Stack

- **Frontend:** React 19, Vite 8, Tailwind CSS v4, Framer Motion
- **Backend:** NestJS 11, Nodemailer (SMTP)
- **Features:** FA/EN bilingual, RTL/LTR, Contact Wizard + Email
